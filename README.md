# UEDemo_MyArua
一个俯视角RPG游戏，整个项目是基于GAS框架进行开发，(70%c++,30%蓝图)，属性系统中：包含4种主要属性，10种二级属性，通过GameplayEffect进行属性配置，次级属性的计算是基于主要属性来计算的，设置了3种敌人职业，分别具有不同的初始化属性，通过DataAsset对每种职业的初始化属性进行集中管理，属性面板和属性数值通过委托进行绑定灵活绑定，UI行为蓝图实现，具体数值计算在c++中，属性可以通过升级获取属性点进行加点，玩家的输入系统使用的是增强输入系统，通过GameAbility进行技能的相关配置，4种主动技能,3种被动技能，每种技能伴随对应的属性伤害，衍生属性中有对属性伤害的抗性。实现了技能的buff效果(灼伤，眩晕，击飞)效果，技能同样可以通过升级获取到的技能点进行学习和升级，技能面板同样通过委托实现UI和数据的绑定进行数据解耦，制作了5种敌人，使用行为树进行AI逻辑，敌人有近战，远程，和召唤师类型。不同类型具有不同的逻辑，通过EQS配置实现绕路行为。技能面板中实现了技能的装配效果，通过Cue进行技能表现效果的实现，升级系统方面：玩家通过击杀敌人获取的经验点进行升级，存档系统方面：制作了主页面，可以存放3个存档，技能面板和属性面板采用的是MVC的架构，存档面板使用MVVM架构，游戏中具有存档点。可以进行关卡之间的切换存档。游戏支持同步，能够支持多人游戏。
